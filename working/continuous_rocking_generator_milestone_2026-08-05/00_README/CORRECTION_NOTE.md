# Correction Note: Möbius Interpretation

An earlier monodromy audit classified the P_line return as a
`Z2=-1 Möbius-line-bundle candidate` because the reduced coefficient mismatch
was normalized by the full Frobenius norm of B(s).

The direct B(s) matrix embedding later showed that the full matrix contains a
large nearly static component. Relative to the much smaller centered moving
geometry, one P_line interval does not return to the same matrix point.
Instead,

    B(s + P_line) - C ~= -[B(s) - C],

and the matrix loop closes after approximately 2 P_line.

Therefore the current evidence supports:

- an antiperiodic tangent return over one half-cycle;
- an alternating two-stroke affine involution;
- a continuous planar rocking generator.

It does not by itself establish a Möbius bundle over a physically closed
P_line coefficient loop.

A Möbius interpretation could become valid only after separately proving that
the antipodal identification

    R ~ -R

is an exact dynamical symmetry defining a legitimate quotient base cycle.
That quotient-symmetry claim remains open.

The earlier monodromy data are preserved for provenance, but this correction
governs the current interpretation.
